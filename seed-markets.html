Seed markets

Admin only. Creates 100 binary markets across 8 categories using real people, clubs, companies and countries (the events themselves are simulated). Each has a resolution period of 2–10 days and a delayed appearance spread over 30 days, so there are always open markets and new ones keep arriving for every user. First it removes the earlier set of made-up markets if they are present. Markets that already exist (same question) are skipped, so it is safe to run twice.
